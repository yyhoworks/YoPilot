# 功能说明

## 运行概览

服务状态与资源使用原生 system/control/metrics。查询类统计使用 query_recorder 的已保留记录，显示采样范围；进程累计请求、QPS、并发、缓存查找使用独立指标，不混作某个查询时间窗的全量统计。

拦截说明只针对可以从配置和执行事件确认的专用应答流程，不把所有 NXDOMAIN/NODATA 当作被拦截。

## 五阶解析拓扑

1. 客户端统计与监听入口。
2. 各自独立的缓存池与累计命中情况。
3. 按用途组织的规则来源，展开查看成员。
4. 原配置中的转发组、并发裁决与主备回退。
5. 具名上游 DNS、地址、协议与累计平均耗时。

实线表示策略拥有的目标，虚线表示用途关联。它是配置结构总览，不是一条实际请求经过的固定流水线；缓存命中、本地过滤、跨策略回退都可能改变执行路径。

分组可锁定高亮，并进入“相关查询”。该关联只按**当前读取页**的原生执行事件 tag 筛选，不是服务器全库分流搜索，不等于精确规则命中。未知/未记录的事件不推断；最多读取 50 条详情，最多 3 并发。

## DNS 与插件

| 分类 | 定义快照数量 | 界面能力 |
| --- | ---: | --- |
| Server | 4 | UDP/TCP/HTTP/QUIC 入口及其原生高级参数 |
| Executor | 35 | 转发、回退、缓存、响应、联动、任务与策略等 |
| Matcher | 20 | 条件参数与原生运行模式能力 |
| Provider | 6 | 域名/IP/Geo/AdGuard/动态集合来源 |

目录与实例数量分开显示。定义包含 247 个顶层字段及嵌套结构；未知字段、自定义表达式和完整 JSON/YAML 路径继续保留。是否能运行以实际 build/config/API 返回为准。

### 上游与出口

按组管理上游目标、协议、并发裁决、主备关系与出口。协议/出口筛选要求同一个目标满足条件，不把组内两个不同节点拼成一次匹配。

缺失引用、出口 profile 或可能的系统 DNS 环回只提供建议；不会悄悄改 dial_addr、Bootstrap、ECS 或出口，不把无样本当离线。

### Hosts 导入

已有 hosts 实例支持标准 IP 在前格式与原生域名在前格式，先预览新增、合并、跳过或替换冲突域名的差异。只保存浏览器草稿 entries；files、正则/关键词复杂记录和未知参数保留。

原生内联 Hosts 不接受行尾 `#` 备注作为注释。导入输入中的备注仅保留在本次浏览器输入/下载中，不作为 IP 写入，不宣称跨刷新持久化。

### 策略编排

条件/动作块支持拖动与键盘上移下移、复制、移除和完整步骤 JSON。中文摘要与静态规则来源预览辅助阅读；无条件终止动作位于中间时提示后续步骤可能不可达，不自动改顺序。

复杂表达式与未知字段原样保留；未确认的 JSON、草稿来源变化和并发编辑受到保护。

## 规则管理

规则源按用途分组，内容、来源/文件、引用与更新任务分开。文件来源数不冒充文件内规则总数，静态引用不冒充运行命中。

动态集合运行分页、新增、移除与清空使用原生 API；它会即时更新运行文件和匹配结果，不等同于编辑初始化规则，也不等待草稿应用。清空需输入完整 tag 并确认。

## 查询与日志

- 原生域名、类型、客户端、响应码、状态与 matcher_tag 筛选；游标翻页。
- 可移除的筛选标签，以及当前浏览器中按服务隔离的常用筛选。
- 可选实际执行插件列；简短摘要与展开后的原始 tag 并存。
- DNS Answer/Authority/Additional、TTL、flags、完整 JSON 与记录到的事件。
- 分组关联导出只包含本页已确认记录，并标出不可用数量。
- 查询/运行日志实时流与历史分页分开；暂停/断流有缺口提示，不声称可靠续传。
- 采样统计最多 10,000 条；域名与客户端去重数不是所有数据库记录或整个局域网设备数。

## 系统与维护

缓存条目删除、dump 导入导出、记录器历史清理、动态集合、本浏览器配置快照使用不同入口、范围与确认，不提供混淆范围的“一键清空全部”。

配置支持顶层块定位/复制、原生校验、备份与来源版本冲突检查。浏览器草稿、服务端文件和运行版本分开展示；保存文件不冒充运行生效。

任务、下载、provider 重载、运行控制与升级使用原生已有能力，并保留原生页面。相关操作均非前端安装步骤，测试也不会自动对生产执行。

## 明确不提供

新增服务端/监听端口、编译或替换 OxiDNS、无限历史聚合、任意外部文件编辑、未记录的精确命中表达式、单节点逐步骤计时，以及超出当前后端构建能力的功能。
