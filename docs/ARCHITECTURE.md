# 架构与数据语义

YoPilot 运行在浏览器中，由原 OxiDNS WebUI 监听器提供静态文件；页面直接调用原生 API。没有代理层、单独登录服务、SQLite 读取进程或额外管理端口。

```text
浏览器 YoPilot
  ├─ 观测 → 原生 health / build / system / metrics / query_recorder
  ├─ 编辑 → 当前浏览器草稿 → 校验/版本检查 → 用户确认应用
  └─ 维护 → 原生插件运行 API → 单独确认 → 回读结果
```

## 模块

| 模块 | 职责 |
| --- | --- |
| `oxidns-engine.js` / 插件目录 | 草稿、通用表单、完整参数、来源版本与原生能力入口 |
| `oxidns-observe*.js` | 原生请求、连接/认证、健康与查询观测、显式写入保护 |
| `oxidns-manage*.js` | 规则来源与 DNS 配置工作区 |
| `oxidns-dynamic*.js` | 动态集合的真实运行时 API，和初始化配置分离 |
| `oxidns-advanced*.js` | 缓存、实时流、配置历史及原生高级运维 |
| `yopilot-path*.js` / `yopilot-causal.js` | 五阶拓扑、用途分组、原始成员及关联入口 |
| `yopilot-overview*.js` / `yopilot-quality.js` | 统计范围、指标投影、上游质量 |
| `yopilot-sequence.js` | 条件与动作顺序编辑、未知字段保留 |
| `yopilot-query-tools.js` / `yopilot-workflow*.js` | 常用筛选、详情关联、导入差异和分类维护 |
| `yopilot-native-pages.js` | 原生采样统计、草稿文件来源；不扩展后台能力 |
| `yopilot-navigation.js` / 样式文件 | 双皮肤、导航布局、缩放与响应式展示 |

## 不能混淆的状态

| 信息 | 正确解释 |
| --- | --- |
| 65 种插件 | 定义快照，不是当前配置实例数 |
| 当前实例 | 由实际服务配置返回，不从示例界面推断 |
| 查询统计 | 所选时段最近至多 10,000 条已保留记录 |
| 缓存/上游计数 | 当前进程累计，不随查询时间窗重算 |
| 用途连线 | 配置分组示意，不是逐请求执行证据 |
| 执行事件 | 原生记录到的 tag/kind/outcome/顺序；不是精确表达式/单步耗时 |
| 记录到转发器 | 不等于知道竞速胜出的具体 DNS 节点 |
| 文件来源路径 | 配置字段，不意味着已读取文件内容 |
| 保存草稿 | 仅本浏览器；不是服务端保存或运行生效 |
| 任务受理 | 不是执行完成；需回读原生状态 |

## 并发与安全边界

连接/版本变化、关闭视图、未确认 JSON 和服务端 409 均不能静默覆盖新数据。配置应用有来源绑定、备份和显式确认；运行数据写操作有各自范围。

关联详情按需读取，至多 3 并发、当前页至多 50 条，内存缓存限制 400 条并按来源隔离。缓存不是浏览器持久化查询数据库。

目录中的原生升级/重启等入口仍然存在，这是功能保留，不是发布 YoPilot 时会执行的行为。
