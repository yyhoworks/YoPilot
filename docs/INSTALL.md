# 安装与回退

## 前提

- 已运行 OxiDNS，且已配置管理 API 和可写的 WebUI 静态目录。
- 当前核对版本为 OxiDNS 1.6.1 full。精简构建的类型/运行 API 以实际 `/api/build` 为准。
- 已备份 WebUI；知道实际配置文件和程序路径。YoPilot 不负责安装、升级或编译 OxiDNS。

本文 `192.0.2.10` 为文档示例地址，需换成自己的设备地址。

## 方式一：复制静态文件

1. 克隆仓库，运行 `npm run check`；运行 `npm run package` 得到 `dist/` 下的 ZIP。
2. 备份整个现有 WebUI 目录到同级、带日期的独立目录。
3. 如尚未安装 YoPilot，先把原 `index.html` 复制为 `native.html`，并保留原 `/plugins`、`/logs`、`/settings` 所需资源。
4. 将静态包中的文件覆盖复制到当前 WebUI 目录。**不是替换整个目录，不删除原生文件。**
5. 在原管理地址打开页面；必要时强制刷新缓存。
6. 检查 `/api/health`、运行配置版本、原生页面以及 DNS 查询响应。

不需要改 OxiDNS 配置格式，不新增监听端口，不启动独立后台。若现有 WebUI 根目录尚未启用，应先按 OxiDNS 官方文档配置；这不是静态发布脚本自动修改的内容。

## 方式二：交互式 SSH 静态发布

```sh
python -m pip install -r requirements.txt
python scripts/deploy-ui.py --host 192.0.2.10 --user root \
  --webroot /opt/oxidns/webui \
  --config /opt/oxidns/config.yaml \
  --binary /opt/oxidns/oxidns
```

Windows PowerShell 可写在一行。非默认 SSH 端口加 `--port`；非默认管理 API 端口加 `--api-port`。

脚本会：

- 使用系统 `known_hosts`，拒绝未知/变更的主机密钥；首次连接需由管理员先核对指纹，不能自动信任未知设备。
- 交互输入 SSH 密码，仅在内存使用，不写文件、源码或命令行参数。
- 核对明确的 WebUI 真实目录，备份整个静态目录。
- 按 `web-assets.json` 白名单上传，核对 SHA-256，先依赖后首页。
- 首次安装时保留原首页副本；不覆盖已有原生副本。
- 对比配置/程序哈希和 OxiDNS PID，读取健康状态。

脚本不会执行编译、服务停止/启动、重启、热重载、更新订阅、清缓存或清历史。它也不变更 API 认证/CORS/TLS。

## 认证与连接

同源部署默认连接当前页面地址。若原生 API 配置了 Basic Auth，可在“服务连接”填写 API 账号；凭据仅用于本页请求，不保存在 localStorage。

**网页 API 账号不是 SSH 账号。** YoPilot 没有新建默认管理员，也不要求把 SSH 密码填到网页。

跨域静态预览可能被 CORS 或浏览器 HTTPS 混合内容规则阻止。优先同源部署；不要通过关闭浏览器安全检查解决连接问题。

## 配置与运行操作

可视化编辑/Hosts 导入/策略排序 → 保存本浏览器草稿 → 原生服务端校验 → 版本检查与备份 → 用户显式应用。

全局配置与原生运行控制有各自限制。网页保留相关能力入口，不意味着安装/更新前端时会自动执行。动态集合、缓存与历史删除是立即影响运行数据的独立操作，必须另行确认。

## 回退

1. 记下发布脚本输出的 `UI_BACKUP`，核对它属于本次 WebUI。
2. 下载或保存当前需要的浏览器草稿。
3. 由管理员仅恢复该备份中的静态文件，或重新发布已验证的旧前端版本。
4. 保留未在本次发布清单中的原生资源，不改 DNS 规则、程序或数据库。
5. 刷新浏览器，核对原生 API 与 DNS 响应。

静态 UI 回退不需要重启 DNS。不要使用含未展开变量/通配符的递归删除命令清理 WebUI。

## 常见问题

**页面有样式但统计为空**：检查服务连接、API 鉴权和 `query_recorder` 是否配置；没有数据不显示假数字。

**插件类型在目录里但不能运行**：目录是定义快照，实际支持取决于当前构建 feature、平台和版本。

**规则文件只能看到路径**：原生接口不提供任意文件读写；使用内联内容、动态集合 API 或管理员原来的文件维护方式。

**升级 OxiDNS 后 UI 被覆盖**：原生升级可能重新安装 WebUI。保留静态包与备份，升级后核对兼容性再重新复制，不借此修改程序。
