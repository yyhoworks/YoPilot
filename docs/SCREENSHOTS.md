# 功能截图

捕获版本：YoPilot 0.1.0 / OxiDNS 1.6.1 full。图片来自实际浏览器界面，不是把概念稿当成已接通功能。公开图片中的地址、查询与客户端等信息已脱敏；遮盖框仅用于保护隐私，不是产品组件。

## 运行概览 · 羊皮纸

![运行概览](screenshots/overview-paper.jpg)

展示服务健康、运行资源、请求与缓存、客户端/域名等统计。查询类统计是有上限的采样，累计指标另行标注。

## 五阶 DNS 解析拓扑

![五阶拓扑](screenshots/topology.jpg)

客户端/监听、缓存、规则来源、策略组、上游 DNS 五列。原始策略与具名节点默认可见；配置关联不冒充实际请求轨迹。

## 规则分组

![规则管理](screenshots/rules.jpg)

按用途集中同类规则源，内容、文件来源、引用和更新操作保持独立。

## 查询与执行事件

![查询日志](screenshots/queries.jpg)

可移除条件、常用筛选和可选执行信息列；原生详情保持可达。真实查询域名/客户端/响应已遮盖。

## 策略编排

![策略编排](screenshots/strategies.jpg)

条件/动作块、中文摘要、规则来源预览、完整步骤 JSON 与拖动/键盘排序。截图仅展示不含敏感参数的编排片段，不展示完整生产配置。

## 毛玻璃外观

![毛玻璃运行概览](screenshots/overview-glass.jpg)

与羊皮纸使用同一套功能；明暗、材质和导航设置不改变 DNS 配置。

## 手机布局

![手机查询工作区](screenshots/mobile.jpg)

模拟手机视口，不声称覆盖所有实体移动设备；表格与拓扑在面板内部滚动，主要操作保留。
